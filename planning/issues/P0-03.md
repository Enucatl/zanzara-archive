## Prerequisites

## Bounded steps

1. Define Transcriber, Diarizer, SpeakerEmbedder and TextEmbedder contracts with capability/fingerprint declarations and typed failures.
2. Define all D5 records, integer millisecond half-open intervals, source/upstream hashes, optional genuine confidence and optional timestamp capability.
3. Freeze service and /api/v1 payload shapes with request IDs, validation and explicit missing-ASR/uncalibrated statuses. Add examples of overlap, no words, invalid vectors and unsupported timestamps.

## Inputs, outputs and failure behavior

Design D5 record list and D10 route table; output typed records, adapter protocols, JSON schemas and synthetic fixtures. Preserve source/model/configuration provenance in outputs and fail without publishing partial artifacts when validation fails. Any interface requiring fabricated timestamps or confidence is a contract blocker.

## Exclusions

No model loading or speculative provider implementations.

## Acceptance checklist

- [ ] Round-trip fixtures retain offsets, speaker scope and model provenance.
- [ ] Text-only transcript results cannot validate as production timed-word artifacts.
- [ ] Wrong dimensions, non-finite/zero vectors, count/order mismatch and out-of-bounds intervals are rejected.
- [ ] Required evidence below is linked and applies to the reviewed commit/configuration.
