- Stable ID: P1-01
- Executor: Luna
- Kind: Implementation

## Outcome and requirement

Human-provisioned access, six model candidates and RTX 5090; output complete model lock and six independently locked service smoke environments.

## Design and interfaces

Use [D1](../SYSTEM-DESIGN.md#d1--packages-and-deployment-boundary), [D5](../SYSTEM-DESIGN.md#d5--models-and-adapters), [D11](../SYSTEM-DESIGN.md#d11--access-and-operational-profiles) and the existing contracts/modules produced by completed prerequisites. The implementation issue establishes only interfaces within this scope; preserve compatible earlier contracts. ## Prerequisites

Parent: [P1](P1.md). Required completed blockers: [P0](P0.md), [P1-H01](P1-H01.md). The preceding phase must have a current Sol PASS and explicit user release. This issue does not depend on its own parent closing.

## Bounded steps

1. Acquire each fixed checkpoint, resolving mutable registry references to immutable revisions and checksums; identify the WavLM fine-tuned verification head explicitly.
2. Build isolated Python 3.11 service images with uv locks and pinned image digests; record preprocessing, dimensions, precision, licenses and runtime versions.
3. Run one real inference through each model on the actual GPU, including finite shape checks and synchronized timing/VRAM measurements; retain private outputs.

## Inputs, outputs and failure behavior

Human-provisioned access, six model candidates and RTX 5090; output complete model lock and six independently locked service smoke environments. Preserve source/model/configuration provenance in outputs and fail without publishing partial artifacts when validation fails. Unavailable checkpoint, incompatible kernels, missing head, ambiguous license or failed GPU smoke is an explicit review blocker.

## Exclusions

No application inference integration, replacement models or full-episode benchmark.

## Acceptance checklist

- [ ] Every model lock field in D5 is populated from observed artifacts, not guessed dimensions or revisions.
- [ ] All six candidates execute on RTX 5090 with recorded driver/CUDA/image evidence.
- [ ] WavLM uses the released fine-tuned checkpoint (Fix pre-train=No) and trained head; ERes2Net revision is v1.0.2.
- [ ] Required evidence below is linked and applies to the reviewed commit/configuration.

## Verification commands

```bash
uv run zanzara models verify --lock models.lock.json
docker compose --profile processing run --rm model-smoke
```

Add the named focused tests/CLI commands in this issue if they do not yet exist; P0-01 establishes common uv/Ruff/pytest commands. Run relevant CPU checks plus the explicitly required real GPU/integration/evaluation actions. Do not treat a mocked model response as measured model quality.
