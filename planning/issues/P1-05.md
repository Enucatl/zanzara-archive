# [P1-05] Local annotation UI and versioned reviewed exports

- Stable ID: P1-05
- Executor: Luna
- Kind: Implementation
- Parent: P1
- Blocked by: P0, P1-04

## Outcome and requirement

Golden draft transcript, audio and turns; output loopback annotation UI and private revisioned exports.

## Design and interfaces

Use [D10](../SYSTEM-DESIGN.md#d10--website-and-api), [E1](../EVALUATION.md#e1--golden-reference-and-transcription-split) and the existing contracts/modules produced by completed prerequisites. The implementation issue establishes only interfaces within this scope; preserve compatible earlier contracts. See [execution rules](../GITHUB-SETUP.md#g7--luna-implementation-handoff-and-release-rules) for selection and evidence.

## Prerequisites

Parent: [P1](P1.md). Required completed blockers: [P0](P0.md), [P1-04](P1-04.md). The preceding phase must have a current Sol PASS and explicit user release. This issue does not depend on its own parent closing.

## Bounded steps

1. Build waveform/timestamp playback with word, speaker-turn, overlap and unintelligible-span editing.
2. Separate machine draft and human-reviewed states; record reviewer/source hash/history and optimistic revision conflicts.
3. Export immutable reference versions, manually timed words and split-ready metadata; keep private annotations outside Git.
4. Provide `zanzara evaluation validate-reference --corpus ... --reference ...` for P1-06 to check schema, full review coverage, split bounds and the >=200-word timing sample without claiming to validate human judgment.

## Inputs, outputs and failure behavior

Golden draft transcript, audio and turns; output loopback annotation UI and private revisioned exports. Preserve source/model/configuration provenance in outputs and fail without publishing partial artifacts when validation fails. Lost edits, ambiguous review ownership or accidental public annotation output block acceptance.

## Exclusions

No automatic ground truth, public exposure or evaluation scores before human review.

## Acceptance checklist

- [ ] A reviewer can correct the full transcript and both overlap/speaker timing annotations.
- [ ] Machine output cannot mark itself human-reviewed.
- [ ] Save/reload/export retains changes, provenance and conflicts without loss.
- [ ] Required evidence below is linked and applies to the reviewed commit/configuration.
