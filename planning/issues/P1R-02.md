# [P1R-02] Define chunk and hypothesis canonical schemas

- Stable ID: P1R-02
- Executor: Luna
- Kind: Implementation
- Parent: P1R
- Blocked by: P0, P1R-01

## Outcome and requirement

Add typed, serializable contracts for `AudioChunk`, `ChunkCondition`, `TranscriptionHypothesis`, `TranscriptReference`, `ReferenceRevision`, and `ChunkBenchmarkManifest`.

## Design and interfaces

`AudioChunk` carries deterministic `chunk_id`, episode/source identity, half-open millisecond interval and segmentation fingerprint. A hypothesis requires only chunk ID, model fingerprint and text; words, segments and raw metadata are optional immutable artifacts. References are append-only and distinguish human truth from drafts.

## Bounded steps

1. Define validation, SQLite/artifact serialization and deterministic IDs.
2. Model condition and speaker-stream structures sufficient for turn taking and genuine overlap without word timing.
3. Add migrations preserving old typed-word artifacts as legacy metadata.

## Inputs, outputs and failure behavior

Input is existing canonical persistence and P1 artifacts. Output is a versioned schema/migration/API contract. Invalid intervals, mismatched hashes or mutable hypothesis writes fail before publication.

## Exclusions

No model adapter, segmentation policy, UI, model-quality claim, or destructive migration.

## Acceptance checklist

- [ ] Text-only, word-timed and segment-timed hypotheses round-trip.
- [ ] Chunk intervals are valid half-open source intervals with stable IDs.
- [ ] Reference revisions retain reviewer, source hash, prior revision and review status.
- [ ] Existing timestamp artifacts remain readable.

## Verification commands

Run focused schema/migration tests, `uv run pytest`, `uv run ruff check .`, and `node planning/validate.mjs`.

## Evidence and documentation

Record migration version, fixture hashes and contract examples using only synthetic text/audio identities.

## Stop conditions and completion rule

Stop if a required legacy artifact cannot be preserved or a contract cannot represent overlap. Complete after migration and synthetic round trips pass.
