# [P1R-03] Implement deterministic adaptive chunk segmentation

- Stable ID: P1R-03
- Executor: Luna
- Kind: Implementation
- Parent: P1R
- Blocked by: P0, P1R-02

## Outcome and requirement

Generate model-independent evaluation chunks using waveform/VAD and available Community-1 boundaries, not ASR punctuation or text.

## Design and interfaces

Freeze configurable `preferred_min_s=8`, `target_s=12`, `preferred_max_s=18`, and `hard_max_s=30`. Prefer meaningful silence, then speaker turns, then generic acoustic boundaries, then hard-duration fallback. Preserve original time and fingerprint every input/configuration.

## Bounded steps

1. Implement deterministic candidate-boundary selection and coverage validation.
2. Produce source-relative half-open intervals without unintended gaps/overlaps in selected regions.
3. Publish segmentation version/configuration with each manifest.

## Inputs, outputs and failure behavior

Inputs are decoded waveform, optional standard diarization and VAD/acoustic boundaries. Output is `AudioChunk` records. Missing optional diarization degrades to acoustic boundaries; invalid source bounds fail.

## Exclusions

No ASR sentence segmentation, human reference editing, model tuning, or archive-wide generation.

## Acceptance checklist

- [ ] Fixtures prefer pause and speaker-turn cuts where available.
- [ ] Hard maximum and complete selected-region coverage are enforced.
- [ ] Identical input/fingerprint produces identical chunks.
- [ ] No evaluated model can influence chunk boundaries.

## Verification commands

Run focused chunker fixtures and `uv run pytest`.

## Evidence and documentation

Record fixtures, configuration hash, source interval coverage and deterministic rerun output hashes.

## Stop conditions and completion rule

Stop if boundary data cannot produce valid coverage. Complete after deterministic synthetic coverage and boundary-priority tests pass.
