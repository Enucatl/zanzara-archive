# [P1R-04] Adapt Parakeet to the chunk-first transcription contract

- Stable ID: P1R-04
- Executor: Luna
- Kind: Implementation
- Parent: P1R
- Blocked by: P0, P1R-02

## Outcome and requirement

Run the existing `nvidia/parakeet-tdt-0.6b-v3` service over frozen chunk audio under the generic text-first hypothesis contract.

## Design and interfaces

Required result is text plus model/configuration/preprocessing fingerprint. Native Parakeet words remain optional raw metadata and are never examined by default chunk scoring.

## Bounded steps

1. Add chunk request/response adaptation using common preprocessing.
2. Persist immutable raw response and native words when supplied.
3. Verify a score can be produced without timestamp access.

## Inputs, outputs and failure behavior

Input is validated frozen chunk audio. Output is one reproducible hypothesis. Invalid audio or unavailable model returns a typed visible failure; it never substitutes another model.

## Exclusions

No removal of word timing, sentence boundary logic, Whisper/Voxtral work, or production-attribution redesign.

## Acceptance checklist

- [ ] Valid chunk returns non-empty text, model fingerprint and optional native words.
- [ ] Exact chunk interval/preprocessing is persisted.
- [ ] Text scoring needs no timestamp field.
- [ ] Legacy Parakeet timestamp behavior is retained.

## Verification commands

Run contract tests, focused Parakeet adapter tests and one private RTX 5090 smoke request.

## Evidence and documentation

Record model/runtime/configuration hash, synthetic response fixture and private GPU smoke metadata.

## Stop conditions and completion rule

Stop on model/runtime incompatibility or non-reproducible output configuration. Complete after contract and real local smoke evidence pass.
