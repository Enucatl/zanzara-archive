# [P1R-05] Add Whisper Large v3 local ASR service

- Stable ID: P1R-05
- Executor: Luna
- Kind: Implementation
- Parent: P1R
- Blocked by: P0, P1R-02

## Outcome and requirement

Provide an accuracy-oriented local adapter for `openai/whisper-large-v3` that transcribes the same frozen chunk audio as Parakeet.

## Design and interfaces

Force/configure Italian consistently, lock decoding where practical, preserve model revision/checksum/runtime/preprocessing, and emit the generic text-first hypothesis. Do not silently use Turbo or a remote fallback.

## Bounded steps

1. Lock model/runtime and implement adapter/service health and typed failures.
2. Freeze decoding/language/preprocessing configuration.
3. Persist raw output and perform real Italian RTX 5090 smoke inference.

## Inputs, outputs and failure behavior

Input is common validated chunk audio. Output is a text hypothesis with provenance. Download, CUDA, memory, or transcription failure stays visible and model-specific.

## Exclusions

No word-timestamp requirement, quality winner claim, remote API, or Turbo substitution.

## Acceptance checklist

- [ ] Real Italian chunk inference on RTX 5090 returns non-empty text.
- [ ] Revision/checksum, image/runtime, precision and decoding settings are recorded.
- [ ] Same interval can be compared directly with Parakeet.
- [ ] No fallback variant/provider is used.

## Verification commands

Run service contract tests and private RTX 5090 health/transcription smoke commands; run CPU tests excluding model downloads.

## Evidence and documentation

Record hardware/driver/CUDA, peak VRAM, runtime, model fingerprint and private smoke artifact hash.

## Stop conditions and completion rule

Stop on inaccessible weights or incompatible GPU runtime. Complete only with current real local smoke evidence and passing contract tests.
