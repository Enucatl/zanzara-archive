# [P1R-06] Add Voxtral Mini 4B Realtime local ASR service

- Stable ID: P1R-06
- Executor: Luna
- Kind: Implementation
- Parent: P1R
- Blocked by: P0, P1R-02

## Outcome and requirement

Add local accuracy-oriented offline chunk transcription for `mistralai/Voxtral-Mini-4B-Realtime-2602`.

## Design and interfaces

Freeze the practical high-quality lookahead/latency configuration, verify Italian on real archive audio, lock revision/checksum and return the same generic text-first hypothesis shape as the other models.

## Bounded steps

1. Implement model lock, service adapter and typed health/error surface.
2. Select and fingerprint offline accuracy configuration rather than minimum streaming delay.
3. Preserve raw response and perform RTX 5090 Italian smoke inference.

## Inputs, outputs and failure behavior

Input is common chunk audio. Output is text/provenance/raw artifact or a visible model-specific failure. No remote fallback or unrecorded lookahead change is allowed.

## Exclusions

No mandatory streaming service, timestamps, model-selection claim, Canary implementation, or cloud call.

## Acceptance checklist

- [ ] Real Italian chunk transcription succeeds locally on RTX 5090.
- [ ] Revision/checksum, configuration, precision, runtime and VRAM are recorded.
- [ ] Output conforms to `TranscriptionHypothesis` with text mandatory.
- [ ] Identical frozen audio can be compared with the other two models.

## Verification commands

Run adapter contracts and private GPU smoke/health tests; run CPU tests without model weights.

## Evidence and documentation

Record pinned model/runtime details, chosen lookahead rationale and private smoke evidence hash.

## Stop conditions and completion rule

Stop if the practical configuration cannot run locally or Italian support is not verified. Complete after evidence and contract tests pass.
