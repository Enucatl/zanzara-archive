# [P1R-07] Orchestrate multi-model chunk inference

- Stable ID: P1R-07
- Executor: Luna
- Kind: Implementation
- Parent: P1R
- Blocked by: P0, P1R-03, P1R-04, P1R-05, P1R-06

## Outcome and requirement

Given a frozen chunk manifest, run Parakeet, Whisper and Voxtral over identical common-preprocessed audio and retain independent immutable hypotheses.

## Design and interfaces

Registration must support a future fourth adapter without schema redesign. Each result records model revision/configuration, preprocessing, raw artifact, runtime and typed error. A missing model is not replaced.

## Bounded steps

1. Implement resumable/idempotent per-model dispatch and reconciliation.
2. Verify source interval/audio bytes match across models except documented transforms.
3. Surface partial failures and exact hypothesis counts.

## Inputs, outputs and failure behavior

Input is a frozen manifest and registered adapters. Output is three separate result streams plus failure records. One model failure does not discard successful peers or claim a complete benchmark.

## Exclusions

No candidate ranking, human reference mutation, automatic gold, scoring, or silent retry/provider substitution.

## Acceptance checklist

- [ ] Each chunk/model result records text or a typed visible failure.
- [ ] Reruns are resumable and idempotent.
- [ ] Common audio identity is reconciled for all models.
- [ ] A fourth adapter can register without database redesign.

## Verification commands

Run orchestration fixtures for success, resume, one-model failure and audio identity; run focused worker tests.

## Evidence and documentation

Record manifest hash, counts by model/status and sample synthetic raw artifact hashes.

## Stop conditions and completion rule

Stop on lost/ambiguous hypothesis provenance. Complete after reconciliation and isolation fixtures pass.
