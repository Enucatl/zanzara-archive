# [P1R-08] Derive diarization and acoustic-condition metadata per chunk

- Stable ID: P1R-08
- Executor: Luna
- Kind: Implementation
- Parent: P1R
- Blocked by: P0, P1R-03

## Outcome and requirement

Attach sampling and slice-reporting metadata to chunks using Community-1 standard/exclusive diarization, while keeping human corrections authoritative.

## Design and interfaces

Derive speaker count, maximum simultaneous speakers, overlap milliseconds/fraction and `has_overlap`. Store editable `music_level`, audio quality and rapid-turn-taking flags with seed/edited provenance.

## Bounded steps

1. Intersect standard/exclusive turns with chunk intervals deterministically.
2. Calculate overlap/speaker aggregates from standard diarization.
3. Add validated human-editable condition revisions.

## Inputs, outputs and failure behavior

Inputs are chunks and Community-1 artifacts. Output is seeded condition metadata. Missing diarization marks unknown rather than inventing labels; invalid interval geometry fails.

## Exclusions

No new music classifier, unquestioned machine truth, speaker identity inference, or lexical scoring.

## Acceptance checklist

- [ ] Fixtures cover one speaker, alternating speakers, two-speaker overlap and three active speakers.
- [ ] Overlap duration/fraction and speaker counts are reproducible.
- [ ] Music/quality/turn-taking corrections are separately versioned.
- [ ] Machine seed is distinguishable from human correction.

## Verification commands

Run condition-metadata fixtures and focused persistence tests.

## Evidence and documentation

Record fixture geometry and metadata schema/version.

## Stop conditions and completion rule

Stop if standard overlap cannot be represented faithfully. Complete after derived and corrected metadata tests pass.
