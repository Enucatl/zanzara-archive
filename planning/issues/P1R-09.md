# [P1R-09] Add local Qwen annotation-assistance service

- Stable ID: P1R-09
- Executor: Luna
- Kind: Implementation
- Parent: P1R
- Blocked by: P0, P1R-07

## Outcome and requirement

Produce a non-authoritative current-chunk review draft using local `Qwen/Qwen3-8B`, current independent hypotheses and up to two preceding reference/draft chunks.

## Design and interfaces

Persist prompt version, model fingerprint, candidate ordering/labels and draft provenance. Prompt demands verbatim fidelity, no grammar improvement/summarization/invention, and output only the current chunk. Randomize or clearly label candidate order.

## Bounded steps

1. Implement replaceable local helper adapter and versioned prompt.
2. Restrict context/output to the current annotation task.
3. Ensure helper failure leaves review fully usable and never changes gold status.

## Inputs, outputs and failure behavior

Input is model hypotheses and bounded prior context. Output is a draft artifact only. Offline/helper errors are displayed, not propagated as reference failure.

## Exclusions

No audio-only claim, automatic reference promotion, model-quality gate, remote LLM, or permanent Qwen architecture commitment.

## Acceptance checklist

- [ ] Draft is distinct from reference and cannot overwrite it.
- [ ] Prompt/model versions and inputs are persisted.
- [ ] Tests enforce current-chunk-only output handling.
- [ ] Review can continue when helper is unavailable.

## Verification commands

Run synthetic prompt/adapter failure tests and focused UI/API contract tests.

## Evidence and documentation

Record prompt hash, model fingerprint and redacted synthetic examples only.

## Stop conditions and completion rule

Stop if provenance or gold isolation cannot be enforced. Complete after offline degradation and non-promotion tests pass.
