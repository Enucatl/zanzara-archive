# [P1R-11] Freeze an 80-chunk ASR pilot

- Stable ID: P1R-11
- Executor: Luna
- Kind: Evaluation
- Parent: P1R
- Blocked by: P1R-03D, P1R-08

Active under the 2026-09-28 working plan; direct prerequisites below replace phase-wide release gates.

## Outcome and requirement

Choose 60 representative and 20 difficult chunks from multiple frozen-corpus episodes.

## Design and interfaces

Split episodes before sampling/tuning, aiming for 40 development and 40 held-out chunks (30 representative/10 difficult each), at least two episodes per partition where available. Select independently of ASR scores; manual music/overlap/degraded tags suffice. Record membership, offsets, reasons and coverage; preserve reviewed work.

Use the [working plan](../README.md), relevant [design contract](../SYSTEM-DESIGN.md) and [evaluation guidance](../EVALUATION.md). Earlier closed issue checklists are historical, not new prerequisites.

## Bounded steps

1. Reuse the existing implementation and direct prerequisite outputs.
2. Deliver the stated behavior within this scope.
3. Run the focused checks and record the outcome once.

## Inputs, outputs and failure behavior

Use the direct prerequisite artifacts and preserve source/model identity and original time offsets where applicable. Missing actual inputs, human truth or a failed correctness check is a concrete blocker; unrelated phase status and metadata are not. Report failures without publishing partial or fabricated output.

## Exclusions

No mandatory 500-chunk campaign, AST calibration gate or separate manifest-approval ceremony; human reference review remains P1R-H01.

## Acceptance checklist

- [ ] Manifest contains the planned sample or explicit coverage shortfalls.
- [ ] Development and held-out episode sets are disjoint and frozen before tuning.
- [ ] Selection is independent of model performance and each chunk has a valid source interval.

## Verification commands

Run focused existing checks for the changed behavior; add a small regression only for new nontrivial logic. Smoke only an affected inference service. No routine full-suite, checkpoint/corpus rehash or unrelated benchmark rerun.

## Evidence and documentation

Record commit, relevant command/result and run ID or artifact path; include model/config/reference versions when material. Keep real audio, text, identities and secrets private. Reuse still-applicable results.
