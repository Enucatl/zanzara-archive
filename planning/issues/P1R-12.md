# [P1R-12] Implement chunk-level ASR scoring harness

- Stable ID: P1R-12
- Executor: Luna
- Kind: Evaluation
- Parent: P1R
- Blocked by: P0, P1R-02

## Outcome and requirement

Score each ASR against identical human truth with conservative versioned Italian normalized WER/CER plus a documented speaker-independent overlap-aware metric such as ORC-WER.

## Design and interfaces

Lock normalizer and scoring library/algorithm versions, retain raw metrics, mask genuinely unintelligible material with documented semantics, and report denominators. Report representative, stress, single speaker, multi-speaker, overlap, music, overlap+music and degraded slices only with meaningful counts.

## Bounded steps

1. Implement text normalization, WER/CER and per-chunk aggregation.
2. Integrate/document ORC-WER or a justified equivalent for overlapping reference streams.
3. Produce private detail and sanitized aggregate report forms without model-specific alignment advantage.

## Inputs, outputs and failure behavior

Inputs are references/hypotheses/conditions. Outputs are versioned metrics/reports; absent valid speaker streams or masks produce explicit unscorable/not-applicable results.

## Exclusions

No timing-error gate, model selection, diarization scoring, or hidden transcript publication.

## Acceptance checklist

- [ ] Known-answer substitution, deletion and insertion fixtures pass.
- [ ] Two-speaker permutation, overlap streams and unintelligible masking are tested.
- [ ] Every slice reports chunk count, duration and reference-word denominator.
- [ ] Metric/library and normalization versions are persisted.

## Verification commands

Run focused ASR metric fixtures, report-schema tests and full CPU test suite.

## Evidence and documentation

Record algorithm/version locks, synthetic expected values and sanitized report schema.

## Stop conditions and completion rule

Stop if overlap scoring semantics cannot be specified and tested. Complete after deterministic known-answer metrics pass.
