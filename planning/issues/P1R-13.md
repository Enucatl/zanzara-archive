# [P1R-13] Rebuild diarization evaluation independently of ASR words

- Stable ID: P1R-13
- Executor: Luna
- Kind: Evaluation
- Parent: P1R
- Blocked by: P0, P1R-02, P1R-08

## Outcome and requirement

Score Community-1 from speaker/overlap intervals and human turn truth, independent of lexical timed words.

## Design and interfaces

Compute DER, JER and speaker-count error with explicit mapping/collar/overlap rules. Where reference supports it, calculate overlap detection precision, recall and F1. Lock a compatible evaluator or cross-check implementation.

## Bounded steps

1. Define interval reference/hypothesis adapters and mapping semantics.
2. Implement aggregate and condition-slice reporting.
3. Add analytically known overlap/confusion fixtures.

## Inputs, outputs and failure behavior

Inputs are turns/overlap intervals and chunk conditions. Outputs are independent diarization metrics. Missing interval truth is unscorable, never inferred from ASR words.

## Exclusions

No lexical WER, word alignment, model change, or automatic speaker identity naming.

## Acceptance checklist

- [ ] DER/JER/speaker-count rules and evaluator version are documented.
- [ ] Synthetic overlap and speaker-confusion values match analytic expectations.
- [ ] Overlap precision/recall/F1 is reported when reference permits.
- [ ] Results do not read transcript word timestamps.

## Verification commands

Run diarization fixtures and focused evaluator cross-check tests.

## Evidence and documentation

Record metric configuration/library versions and synthetic expected results.

## Stop conditions and completion rule

Stop if interval geometry/mapping is ambiguous. Complete after independent fixture evidence passes.
