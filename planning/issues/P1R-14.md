# [P1R-14] Implement integrated who-said-what scoring

- Stable ID: P1R-14
- Executor: Luna
- Kind: Evaluation
- Parent: P1R
- Blocked by: P0, P1R-02, P1R-12, P1R-13

## Outcome and requirement

Measure combined transcription and diarization distinctly from either standalone score using documented cpWER and, where meaningful, tcpWER.

## Design and interfaces

Specify channel/permutation mapping, reference/hypothesis speaker streams, overlap treatment, interval constraints and denominator behavior. Preserve raw mapping decisions in private artifacts.

## Bounded steps

1. Implement cpWER with explicit speaker permutation behavior.
2. Add tcpWER only if time-constrained semantics can be locked/tested.
3. Produce separate integrated reports rather than relabeling lexical WER as speaker WER.

## Inputs, outputs and failure behavior

Inputs are multi-stream reference, ASR hypotheses and diarization result. Outputs are integrated metrics or explicit unscorable result. Missing speaker streams never silently become speaker-independent WER.

## Exclusions

No custom undefined “speaker WER”, word-timing gold, production attribution rewrite, or model winner assertion.

## Acceptance checklist

- [ ] Fixtures cover correct words/wrong speaker, wrong words/correct speaker, swapped labels and overlap.
- [ ] cpWER mapping/permutation is documented and persisted.
- [ ] tcpWER is either locked/tested or explicitly deferred with rationale.
- [ ] Integrated output is clearly separate from ASR and diarization reports.

## Verification commands

Run integrated metric fixtures and report-schema tests.

## Evidence and documentation

Record metric definitions, versions and synthetic mapping examples.

## Stop conditions and completion rule

Stop if mapping semantics are not reproducible. Complete after known-answer integrated fixtures pass.
