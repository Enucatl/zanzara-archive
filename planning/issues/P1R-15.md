# [P1R-15] Evaluate human-review assistance effectiveness

- Stable ID: P1R-15
- Executor: Luna
- Kind: Evaluation
- Parent: P1R
- Blocked by: P0, P1R-H01

## Outcome and requirement

Measure which starting draft best reduces annotation effort; do not confuse this with independent ASR quality or make it a P1R release gate.

## Design and interfaces

Compare Parakeet, Whisper, Voxtral and Qwen synthesis against final human gold using edit distance, optional reliable review duration and edit counts. Keep presentation/order and sampling limitations explicit.

## Bounded steps

1. Derive draft-to-final measurements from immutable revisions.
2. Aggregate by condition and report counts/durations.
3. Separate ergonomics conclusion from ASR selection report.

## Inputs, outputs and failure behavior

Inputs are reviewed references and drafts. Output is an annotation-assistance report. Missing reliable duration means omit that metric rather than inventing it.

## Exclusions

No release threshold, gold rewriting, ASR quality substitution, or hidden reviewer content.

## Acceptance checklist

- [ ] All four starting-draft categories are compared where data exists.
- [ ] Report labels assistance metrics separately from ASR metrics.
- [ ] Counts and data-quality limitations are disclosed.

## Verification commands

Run measurement/aggregation fixtures and report tests.

## Evidence and documentation

Record revision hashes, aggregation configuration and sanitized findings.

## Stop conditions and completion rule

Stop if revisions cannot identify draft provenance. Completion is optional and does not block P1R release.
