# [P1R-16] Execute three-model benchmark and publish selection report

- Stable ID: P1R-16
- Executor: Luna
- Kind: Evaluation
- Parent: P1R
- Blocked by: P0, P1R-07, P1R-11, P1R-H01, P1R-12, P1R-13, P1R-14

## Outcome and requirement

Run the first real comparative benchmark and make a production-ASR recommendation from measured archive evidence, not implementation order.

## Design and interfaces

Required rows are Parakeet, Whisper Large v3 and Voxtral Mini 4B Realtime 2602. Report representative/stress WER and CER, overlap-aware ASR, music/overlap+music/degraded slices, diarization/integrated results where applicable, failures, throughput, GPU runtime, VRAM, real-time factor and model revisions.

## Bounded steps

1. Freeze all manifest/reference/configuration/scoring inputs before report execution.
2. Execute each model through common orchestration and reconcile failures.
3. Publish a sanitized aggregate report and explicit recommendation/policy if no single model wins.

## Inputs, outputs and failure behavior

Inputs are frozen chunks, human gold and scoring harnesses. Output is an immutable run/report. Failed/unsupported chunks remain visible; no model can receive privileged boundary/alignment handling.

## Exclusions

No preset winner, accuracy threshold invention, cloud API, Canary requirement, or release action.

## Acceptance checklist

- [ ] All three required model rows have provenance and complete count reconciliation.
- [ ] Every reported slice includes chunk count, duration and word denominator.
- [ ] Resource/failure/unsupported-chunk data accompanies quality results.
- [ ] Recommendation is explicitly tied to measured evidence and limitations.

## Verification commands

Run the private benchmark command on RTX 5090, report validator and focused CPU scoring tests.

## Evidence and documentation

Record commit, manifest/reference/partition/normalizer/scoring hashes, model/runtime/hardware details and sanitized report URL/hash.

## Stop conditions and completion rule

Stop on incomplete gold, unfrozen held-out membership, missing model provenance or unreconciled failures. Complete after one reproducible three-model report exists.
