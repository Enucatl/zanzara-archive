# [P1R-17] Rewrite release gates and downstream dependency contracts

- Stable ID: P1R-17
- Executor: Luna
- Kind: Implementation
- Parent: P1R
- Blocked by: P0, P1R-01, P1R-16

## Outcome and requirement

Make the measured P1R evaluation framework authoritative across future planning, release checks and native dependencies without disturbing separate voice-retrieval or text-search evaluation.

## Design and interfaces

Update `planning/EVALUATION.md`, `planning/SYSTEM-DESIGN.md`, manifests, GitHub dependencies and release references. Replace old golden five-block, timed-word and mandatory-timestamp requirements with chunk manifests, episode-level splits and separate ASR/diarization/integrated measures.

## Bounded steps

1. Apply P1R-01 migration decisions and P1R-16 measured report vocabulary.
2. Reconcile applicable downstream blockers to P1R release and read native edges back.
3. Preserve unrelated voice/text metrics and historical P1 evidence labels.

## Inputs, outputs and failure behavior

Inputs are migration record and benchmark report. Outputs are authoritative documents/manifests/live dependencies. A conflict or unclear consumer blocks change rather than silently weakening a future gate.

## Exclusions

No deletion of production word attribution, voice retrieval evaluation, text relevance evaluation, history, or newly invented ASR thresholds.

## Acceptance checklist

- [ ] No downstream task requires 200 timed words, the old five-block gold, or ASR timestamps merely to benchmark text.
- [ ] P1R release is the named transcription-quality dependency where applicable.
- [ ] Voice and text evaluation contracts remain independently intact.
- [ ] Planning and native GitHub graph read back consistently.

## Verification commands

Run `node planning/validate.mjs` and GITHUB-SETUP G6 dependency/body read-back commands.

## Evidence and documentation

Record changed references, native-edge before/after map, planning commit and report hash.

## Stop conditions and completion rule

Stop on downstream-contract ambiguity or remote conflict. Complete after authoritative documents and live graph consistently reference P1R.
