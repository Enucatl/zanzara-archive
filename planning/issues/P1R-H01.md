# [P1R-H01] Human: review and finalize chunk gold references

- Stable ID: P1R-H01
- Executor: Human
- Kind: Operator
- Parent: P1R
- Blocked by: P0, P1R-10, P1R-11

## Outcome and requirement

Create genuinely human-verified reference text and appropriate speaker/condition truth for every benchmark chunk, using candidates only as editable starting drafts.

## Design and interfaces

The reviewer listens to actual chunk audio, preserves repetitions, false starts, profanity and colloquial speech, marks unintelligible content honestly, and corrects obvious speaker/overlap/music/quality seeds. No individual word timing is required.

## Bounded steps

1. Listen, edit and approve each assigned chunk in the review UI.
2. Represent multi-speaker turn taking and genuine overlap as distinct streams where supported.
3. Record unresolved/unscorable reasons rather than guessing.

## Inputs, outputs and failure behavior

Inputs are frozen manifest, audio and candidate drafts. Outputs are append-only reviewed revisions with reviewer/time/source hash. Missing human listening leaves status unreviewed or adjudication-needed.

## Exclusions

No automatic candidate acceptance, whole-episode requirement, word-boundary timing, or obligation to accept diarization labels.

## Acceptance checklist

- [ ] Every benchmark chunk has a reviewed reference or explicit unresolved/unscorable reason.
- [ ] Each reviewed revision identifies reviewer, date, source hash and prior revision.
- [ ] Text truth was checked against audio, not merely candidate consensus.
- [ ] Corrected conditions/speaker structure retain review provenance.

## Verification commands

Use the review UI's private reference validation and manifest reconciliation command; review counts must match manifest counts.

## Evidence and documentation

Record private reference/revision hashes, reviewer/date, review counts and unresolved reasons; do not publish audio/transcript content.

## Stop conditions and completion rule

Stop if UI cannot represent the heard truth; open a bounded Luna follow-up. Complete after all manifest entries reconcile to reviewed or explicit unscorable status.
