# [P2-05] Qdrant exemplar and centroid generations

- Stable ID: P2-05
- Executor: Luna
- Kind: Implementation
- Parent: P2
- Blocked by: P1, P2-01, P2-02, P2-03, P2-04

## Outcome and requirement

Clean exemplars and all three adapters; output complete rebuildable voice collections for the frozen corpus.

## Design and interfaces

Use [D3](../SYSTEM-DESIGN.md#d3--canonical-data-and-publication), [D7](../SYSTEM-DESIGN.md#d7--voice-retrieval-and-identity) and the existing contracts/modules produced by completed prerequisites. The implementation issue establishes only interfaces within this scope; preserve compatible earlier contracts. See [execution rules](../GITHUB-SETUP.md#g7--luna-implementation-handoff-and-release-rules) for selection and evidence.

## Prerequisites

Parent: [P2](P2.md). Required completed blockers: [P1](P1.md), [P2-01](P2-01.md), [P2-02](P2-02.md), [P2-03](P2-03.md), [P2-04](P2-04.md). The preceding phase must have a current Sol PASS and explicit user release. This issue does not depend on its own parent closing.

## Bounded steps

1. Run all three encoders on every retained exemplar, retaining source vectors as immutable artifacts.
2. Build named-vector exemplar and separate normalized-mean centroid collections with deterministic IDs and payload indexes.
3. Publish a verified collection bundle pointer only after all expected points validate; make retries/upserts idempotent and preserve old generations.

## Inputs, outputs and failure behavior

Clean exemplars and all three adapters; output complete rebuildable voice collections for the frozen corpus. Preserve source/model/configuration provenance in outputs and fail without publishing partial artifacts when validation fails. Any missing encoder or incomplete generation blocks publication.

## Exclusions

No automatic identities, text vectors or reuse of an unrelated Qdrant service.

## Acceptance checklist

- [ ] All indexable exemplars have resnet293, eres2net and wavlm vectors with locked dimensions.
- [ ] Index rebuild from local artifacts matches counts and retrieval fixtures without re-inference.
- [ ] A partial write/crash never switches active generation or mixes model spaces.
- [ ] Required evidence below is linked and applies to the reviewed commit/configuration.
