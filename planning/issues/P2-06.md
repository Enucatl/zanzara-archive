# [P2-06] Candidate retrieval and robust exemplar verification

- Stable ID: P2-06
- Executor: Luna

## Outcome and requirement

Published voice generation and archive episode-speaker ID; output ranked candidate API/CLI with auditable scores.

## Design and interfaces

Use [D7](../SYSTEM-DESIGN.md#d7--voice-retrieval-and-identity), [D10](../SYSTEM-DESIGN.md#d10--website-and-api) and the existing contracts/modules produced by completed prerequisites. ## Prerequisites

Parent: [P2](P2.md). Required completed blockers: [P1](P1.md), [P2-05](P2-05.md). The preceding phase must have a current Sol PASS and explicit user release. This issue does not depend on its own parent closing.

## Bounded steps

1. Union top 50 centroid hits per encoder with default same-episode exclusion before limiting.
2. Perform deterministic one-to-one exemplar matching separately per model and median matched-pair scores.
3. Return all model diagnostics, representative audio, provenance and uncalibrated reciprocal-rank fusion until a valid calibration artifact exists.
4. Provide a private candidate audio/label worksheet export and `zanzara evaluation validate-voice-labels --labels ... --split ...` for P2-07, validating schema, source references, group leakage and eligible query/gallery membership. Human review supplies labels; metric fitting belongs to P2-08.

## Inputs, outputs and failure behavior

Published voice generation and archive episode-speaker ID; output ranked candidate API/CLI with auditable scores. Preserve source/model/configuration provenance in outputs and fail without publishing partial artifacts when validation fails. Missing model/generation or untraceable diagnostic score blocks ensemble results.

## Exclusions

No full website, automatic merges or cascade optimization.

## Acceptance checklist

- [ ] Candidate union, tie order, one-to-one endpoint use and medians match known synthetic examples.
- [ ] Default results exclude the query episode; all models participate in verification.
- [ ] Response labels uncalibrated rank fusion accurately and does not present it as probability.
- [ ] Required evidence below is linked and applies to the reviewed commit/configuration.

## Verification commands

```bash
uv run pytest tests/test_voice_retrieval.py tests/test_exemplar_matching.py
uv run zanzara voice search --speaker "$ZANZARA_EPISODE_SPEAKER_ID"
```

Add the named focused tests/CLI commands in this issue if they do not yet exist; P0-01 establishes common uv/Ruff/pytest commands. Run relevant CPU checks plus the explicitly required real GPU/integration/evaluation actions. Do not treat a mocked model response as measured model quality.
