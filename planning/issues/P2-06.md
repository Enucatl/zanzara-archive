# [P2-06] Retrieve and verify ResNet voice candidates

- Stable ID: P2-06
- Executor: Luna
- Kind: Implementation
- Parent: P2
- Blocked by: P2-05

Active under the 2026-09-28 working plan; direct prerequisites below replace phase-wide release gates.

## Outcome and requirement

Given an archive episode speaker, return recurring-voice candidates in other episodes.

## Design and interfaces

Retrieve top-50 ResNet centroids excluding the query episode by default, then use the existing D7 deterministic one-to-one exemplar matching and median similarity to rerank. Return representative excerpts, provenance and uncalibrated scores. Keep speakers without eligible exemplars explicit.
