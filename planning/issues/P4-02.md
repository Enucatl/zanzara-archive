# [P4-02] Text search, transcripts and timestamped audio playback

- Stable ID: P4-02
- Executor: Luna
- Kind: Implementation
- Parent: P4

## Outcome and requirement

Search/transcript APIs and validated media IDs; output complete text discovery and listening pages.

## Design and interfaces

Use [D6](../SYSTEM-DESIGN.md#d6--transcript-production), [D9](../SYSTEM-DESIGN.md#d9--text-retrieval), [D10](../SYSTEM-DESIGN.md#d10--website-and-api) and the existing contracts/modules produced by completed prerequisites. See [execution rules](../GITHUB-SETUP.md#g7--luna-implementation-handoff-and-release-rules) for selection and evidence.

## Prerequisites

Parent: [P4](P4.md). Required completed blockers: [P3](P3.md), [P4-01](P4-01.md). The preceding phase must have a current Sol PASS and explicit user release. This issue does not depend on its own parent closing.

## Bounded steps

1. Implement mode/filter controls, excerpts and visible degraded-mode messaging.
2. Render word-linked transcript playback, active word highlighting and standard-overlap indicators.
3. Serve valid media intervals with browser seeking/range behavior; preserve context around search hits and explicit ASR-missing state.

## Inputs, outputs and failure behavior

Search/transcript APIs and validated media IDs; output complete text discovery and listening pages. Preserve source/model/configuration provenance in outputs and fail without publishing partial artifacts when validation fails. Incorrect original offsets, broken seeking or unauthorized file resolution blocks completion.

## Exclusions

No transcript rewrites or remote URL proxying.

## Acceptance checklist

- [ ] A synthetic query leads to the correct episode/word time and playable interval.
- [ ] Invalid IDs, traversal attempts and out-of-range timestamps never access arbitrary files.
- [ ] Overlap and lexical fallback are visible and keyboard controls work.
- [ ] Required evidence below is linked and applies to the reviewed commit/configuration.
