## Bounded steps

1. Define processing/serving/exposure profiles with one shared worker, dedicated Qdrant, local volumes and read-only archive.
2. Pin built/runtime images, use uv locks/cache layers and liveness/readiness checks; map only permitted loopback web access until tunnel provisioning.
3. Document all paths, model endpoints, secret locations, limits and initial resource assumptions pending measurements.

## Inputs, outputs and failure behavior

Integrated app/services and model locks; output production Compose profiles, health checks and configuration docs. Preserve source/model/configuration provenance in outputs and fail without publishing partial artifacts when validation fails. Public internal services, writable archive mount or network-backed SQLite block acceptance.

## Exclusions

No Kubernetes, extra worker pools or GPU capacity claims before P5-04.
