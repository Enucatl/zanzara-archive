## Bounded steps

1. Implement origin Access JWT validation for signature/algorithm/JWKS rotation, issuer/audience/expiry/not-before across pages/static/API/media/reports.
2. Enforce CSRF on mutations and fail closed on missing/invalid authentication; keep health probes internal.
3. Route only web through cloudflared, verify direct-origin protection and document operator provisioning/rollback steps.

## Inputs, outputs and failure behavior

Production Compose and human Cloudflare configuration; output protected exposure and tested runbook. Preserve source/model/configuration provenance in outputs and fail without publishing partial artifacts when validation fails. Any auth bypass, missing operator configuration or inability to validate production access blocks release.

## Exclusions

No exposure of Qdrant/model APIs or changes to unrelated Cloudflare applications.
