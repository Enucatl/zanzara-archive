# [P5-04] Concurrent GPU benchmark and measured serving defaults

- Stable ID: P5-04
- Executor: Luna
- Kind: Evaluation
- Parent: P5
- Blocked by: P4, P5-01

## Outcome and requirement

Actual RTX 5090 and Compose serving/processing profiles; output measured residency/latency report and resource defaults.

## Design and interfaces

Use [D11](../SYSTEM-DESIGN.md#d11--access-and-operational-profiles), [E6](../EVALUATION.md#e6--operational-measurements-and-report-format) and the existing contracts/modules produced by completed prerequisites. The implementation issue establishes only interfaces within this scope; preserve compatible earlier contracts. See [execution rules](../GITHUB-SETUP.md#g7--luna-implementation-handoff-and-release-rules) for selection and evidence.

## Prerequisites

Parent: [P5](P5.md). Required completed blockers: [P4](P4.md), [P5-01](P5-01.md). The preceding phase must have a current Sol PASS and explicit user release. This issue does not depend on its own parent closing.

## Bounded steps

1. Measure all three encoders plus text/processing model residency, cold/warm requests and concurrent search/processing contention.
2. Record peak/free VRAM, RAM, queue time and throughput with sampling method and container/driver fingerprints.
3. Reserve >=4 GiB GPU headroom; if exceeded serialize heavy processing and document the measured serving profile and wait behavior.

## Inputs, outputs and failure behavior

Actual RTX 5090 and Compose serving/processing profiles; output measured residency/latency report and resource defaults. Preserve source/model/configuration provenance in outputs and fail without publishing partial artifacts when validation fails. OOM, insufficient headroom or unmeasured concurrency blocks resource acceptance.

## Exclusions

No assumed 5090 capacity, cascade optimization or performance estimate presented as measurement.

## Acceptance checklist

- [ ] Measured deployed profile retains >=4 GiB VRAM headroom under the tested workload.
- [ ] Full ensemble is measured first and no encoder is silently removed to fit memory.
- [ ] Published defaults and expected latency reflect actual runs, including serialization when necessary.
- [ ] Required evidence below is linked and applies to the reviewed commit/configuration.

## Verification commands

```bash
uv run zanzara benchmark runtime --profiles serving,processing --min-headroom-gib 4 --output "$ZANZARA_RUNTIME_REPORT"
```

Add the named focused tests/CLI commands in this issue if they do not yet exist; P0-01 establishes common uv/Ruff/pytest commands. Run relevant CPU checks plus the explicitly required real GPU/integration/evaluation actions. Do not treat a mocked model response as measured model quality.
