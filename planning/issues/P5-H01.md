Chosen private deployment/domain and operator accounts; output secret configuration and Access policy evidence.

Use [D11](../SYSTEM-DESIGN.md#d11--access-and-operational-profiles) and the existing contracts/modules produced by completed prerequisites. The implementation issue establishes only interfaces within this scope; preserve compatible earlier contracts. ## Prerequisites

Parent: [P5](P5.md). Required completed blockers: [P4](P4.md). The preceding phase must have a current Sol PASS and explicit user release. This issue does not depend on its own parent closing.

## Bounded steps

1. Select domain/hostname, Access organization/issuer/audience and allowed-user policy; create the tunnel and Access application through operator credentials.
2. Provision private tunnel token, Access settings, local volume/archive locations and backup destination.
3. Record redacted resource IDs/configuration completion and intended web-only tunnel route; P5-02 verifies enforcement before exposure.

## Inputs, outputs and failure behavior

Chosen private deployment/domain and operator accounts; output secret configuration and Access policy evidence. Preserve source/model/configuration provenance in outputs and fail without publishing partial artifacts when validation fails. Missing domain/policy/credentials or unsafe storage placement blocks exposure.

## Exclusions

No public bypass hostname, wildcard internal service routes or unattended account provisioning by Luna.

## Acceptance checklist

- [ ] Required configuration is supplied without secrets in repository/issues.
- [ ] Access policy covers the entire hostname and operator confirms intended allowed users.
- [ ] Required evidence below is linked and applies to the reviewed commit/configuration.

Operator evidence: redacted domain/Access/tunnel/local-storage checklist and private credentials available.

The operator performs the action/review; CLI validation checks format and completeness, never substitutes for human judgment. If a required validation command is missing, request a bounded Luna follow-up rather than pretending this Human task implemented it.

Record exact commands/results, reviewed commit, artifact/source/model/split hashes where applicable, and the private evidence path. Update the relevant interface/runbook documentation for implemented behavior. Public issues/PRs contain sanitized aggregate results and synthetic examples only. Include the human actor, action date and explicit decision; never publish credentials or private annotations.

Missing domain/policy/credentials or unsafe storage placement blocks exposure. Complete only when the human action and acceptance evidence are recorded. Keep [P5](P5.md) open for Sol review and user release.
